# 📄 Interactive Resume Builder

A web-based Interactive Resume Builder that allows users to enter their personal, education, and experience details while viewing a live resume preview.

## ✨ Features

- 👤 Personal information form
- 🎓 Add multiple education entries
- 💼 Add multiple experience entries
- ✏️ Live resume preview
- ➕ Add education and experience
- ➖ Remove education and experience
- 🖨️ Print resume
- 📄 Save resume as PDF using the browser print option
- 📱 Responsive design
- 🖥️ Print-friendly resume layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser Print API
